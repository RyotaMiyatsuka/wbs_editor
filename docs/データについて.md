# データについて

## 共通の前提条件

- 日付は yyyy/mm/dd 形式

## データ一覧

### タスク一覧

#### 概要

- タスクの一覧
- このタスクをもとに WBS を作成する。

#### カラム

- task_id: タスク id
- task_name: タスク名
- priority: 優先度。数値の形式で指定。
- assignee: 担当者
- deadline_date: 期限
- estimated_hours: 予定時間
- predecessor_task_ids: 着手条件。カンマ区切りのタスク id で指定する

### 人員一覧

#### 概要

- 人員の一覧
- 割り当てられる時間などを設定できる

#### カラム

- employee_id
- name
- available_hours_per_day

### カレンダー

#### 概要

- カレンダー
- 人員別に稼働時間を指定する

#### カラム

- employee_id
- date
- day_of_week
- available_hours
